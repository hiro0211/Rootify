## 1. プロダクトビジョン

### 1.1 一言で

> **英単語を「根っこ」から理解する。最小の努力で最大の語彙を手に入れるアプリ。**

### 1.2 コンセプトステートメント

Rootify は、英単語を何度覚えてもすぐ忘れてしまう日本人社会人が、**語源（接頭辞＋語根＋接尾辞）** という「単語の設計図」を理解することで、丸暗記に頼らず効率的に語彙を増やし、TOEIC 600点突破と「英語ができる自分」という自己信頼を手に入れるアプリである。

1つの語源を覚えれば、そこから派生する5〜10の単語が芋づる式にわかる。これが「最小の努力で最大の結果」を実現する仕組みであり、Rootify の核心的な提供価値である。

### 1.3 プロダクト原則（守るべき判断基準）

| # | 原則 | 意味 |
|---|------|------|
| 1 | **根っこから理解する** | 単語と意味の1対1暗記はさせない。語源パーツから意味を組み立てる体験を提供する |
| 2 | **覚えるのではなく、わかる** | 「暗記した」ではなく「構造を理解した」が正しいゴール。未知語の意味を推測できる力を育てる |
| 3 | **通勤10分で完結する** | 1セッション10問・5〜10分で完了する設計。まとまった時間がなくても毎日続けられる |
| 4 | **楽しさが継続を生む** | 単調な4択の繰り返しにしない。語源ツリーで「芋づる式に覚える快感」を提供する |
| 5 | **苦手意識を否定しない** | 「英語が苦手」は恥ではない。語源を知らなかっただけ。正しいツールを使えば誰でもできる |

| 項目 | 内容 |
|------|------|
| 英語に対する感情 | コンプレックス。「自分は暗記が苦手だから英語ができない」と思い込んでいる |
| 挫折後の感情 | 「また続かなかった」→「やっぱり自分には英語は無理なんだ」→ 学習意欲がさらに低下する悪循環 |
| 語源に出会った時の反応 | 「ex- = 外へ」を知った瞬間、exclude, expression, extreme が一気に繋がった。「暗記じゃなくて理解すればいいのか」と目から鱗が落ちた |
| 課金の心理 | 「本当に効果があるなら月500円は安い」。ただし過去に何度も教材を買って挫折しているため、無料で効果を実感してからでないと財布を開かない |

### 2.5 語源学習の原体験

> **「ex- = 外へ出る」を知った瞬間の体験：**
>
> exclude = ex（外へ）+ clude（閉じる）= 外へ閉め出す → 排除する
> expression = ex（外へ）+ press（押す）= 外へ押し出す → 表現
> extreme = ex（外へ）+ treme（端）= 外の端 → 極端な
>
> 「全部 "外へ出る" がベースじゃん！」と気づいた瞬間、3つの単語が丸暗記ではなく構造として頭に入った。
> これまで個別に覚えようとしていた単語が、1つの「根っこ」で繋がる快感。
> **「自分は暗記が苦手なんじゃなくて、覚え方を知らなかっただけだ」** と思えた。

## 4. 課題の構造分析 — 丸暗記の悪循環

### 4.1 従来の英単語学習が失敗するメカニズム

田中 翔太が英単語学習で挫折するパターンは「怠けている」のではない。以下の悪循環にハマっている。

```
[Stage 1] 英単語帳を開く / アプリを起動する
    │
    │  「apple = りんご」式の1対1暗記を繰り返す
    ▼
[Stage 2] 短期記憶には入る（その場では正解できる）
    │
    │  しかし語源的な構造理解がないため、記憶のフックがない
    ▼
[Stage 3] 1週間後、同じ単語に再会しても思い出せない
    │
    │  「また忘れた…」→ 自己効力感が低下
    ▼
[Stage 4] 同じ単語を3回目、4回目に学習する
    │
    │  「何度やっても覚えられない」→ 作業が苦痛になる
    ▼
[Stage 5] 学習が義務感に変わり、モチベーションが消える
    │
    ▼
[Stage 6] 教材を閉じる / アプリを削除する
    │
    │  「自分は暗記が苦手だから英語は無理」という自己認知が強化
    ▼
[Stage 7] 次の教材を買う → Stage 1 に戻る（悪循環）
```

### 4.2 悪循環の根本原因

| 原因 | 説明 |
|------|------|
| **記憶のフックがない** | 「precede = 先行する」を丸暗記しても、「pre（前に）+ cede（進む）= 前に進む → 先行する」という構造を知らなければ、記憶に引っかかるポイントがない |
| **関連付けがない** | precede, proceed, exceed, succeed はすべて「cede/ceed = 進む」が共通語根。だが丸暗記では4つの独立した単語として扱うため、4倍の暗記負荷がかかる |
| **理解なき反復は退屈** | 意味がわからないまま繰り返すのは「写経」と同じ。脳が意味を見出せない反復は苦痛として処理される |
| **成功体験がない** | 「覚えた！」と思っても忘れる。この失敗の繰り返しが「自分は英語ができない」という自己認知を強化する |

### 4.3 Rootify が断ち切る悪循環

```
[従来] 単語 → 丸暗記 → 忘れる → 再暗記 → 苦痛 → 挫折
                            ↓
[Rootify] 語源パーツを学ぶ → 構造で理解する → 関連語が芋づる式にわかる
           → 忘れにくい → 未知語も推測できる → 「できる」実感 → 継続
```

**核心的な構造転換：** 従来のアプリは「単語 → 意味」の1対1マッピングを反復させる。Rootify は「語源パーツ → 単語群」の1対多マッピングで学習させる。1つの語源を理解すれば5〜10の単語が「わかる」。これにより暗記負荷が構造的に減少し、「覚えられない」問題の根本原因を解消する。

```
    │  「duct = 導く」→ conduct, produce, reduce, introduce…
    ▼
[自動] 間隔反復で忘れかけた単語が翌日以降のクイズに再登場
```

| 3ヶ月 | 60〜80個 | 400〜600語 | 500点 → 600点圏内 |
| 6ヶ月 | 100〜120個 | 700〜1000語 | 600点安定 |

## 7. 科学的根拠に基づく学習設計

### 7.1 語源学習（Morphological Awareness）の有効性

**根拠①：形態素意識と語彙定着の関係**

Permangil（2025）のミックスメソッド研究（185名対象）で、形態素意識（morphological awareness）と語彙定着の間に有意な正の相関が確認された。接頭辞・語根・接尾辞を分解して理解する能力が高い学習者ほど、語彙の長期保持率が高い。

Rootify への応用：すべての単語を「接頭辞＋語根＋接尾辞」に分解して表示し、パーツの意味から単語全体の意味を組み立てる学習体験を提供する。

**根拠②：語源戦略による未知語推測能力の向上**

Trexler et al.（2023）の研究で、語源戦略（etymological strategies）を用いた学習者は未知語の意味推測において有意な改善を示し、さらに学習者自身がこの戦略を楽しいと報告したことが確認されている。

Rootify への応用：クイズモードに「語源ヒント」を表示し、正解を暗記ではなく語源パーツから推測させる設計にする。

**根拠③：組織化された情報の記憶優位性**

津田塾大学の稲垣准教授（第二言語習得研究者）は、「人間の脳はバラバラの情報よりも、関連付けられた情報の方が記憶しやすい」ことを指摘。語源ごとにグルーピングした学習が、ランダムな単語リストよりも記憶効率が高いことを示している。

Rootify への応用：語源ツリーマップで同一語根の単語を視覚的にグルーピング。「duct = 導く」の下に conduct, produce, reduce, introduce をまとめて表示する。

### 7.2 間隔反復（Spaced Repetition）の有効性

**根拠④：エビングハウスの忘却曲線と間隔反復**

1880年代にHermann Ebbinghausが発見した忘却曲線は、学習直後から記憶が急速に減衰することを示した。しかし、適切なタイミングで復習を行うことで、忘却曲線が緩やかになり、少ない復習回数で長期記憶に移行できることが実証されている。

**根拠⑤：Duolingo の間隔反復モデル**

Settles & Meeder（2016、ACL発表）のDuolingo研究では、学習者のパフォーマンスデータに基づく適応型間隔反復アルゴリズムが、固定間隔よりも効率的な語彙定着を実現することを示した。

**根拠⑥：コンピュータベース間隔反復の実験検証**

Chukharev-Hudilainen & Klepikova（2016）の研究で、コンピュータベースの間隔反復システムが、従来の学習方法と比較して語彙習得において有意に優れた成績を示すことが確認された。

Rootify への応用：語源学習と間隔反復を組み合わせる。語源パーツで「理解」した上で、間隔反復で「定着」させる。理解＋反復の二重構造により、丸暗記＋反復よりも少ない復習回数で長期記憶に移行する。

### 7.3 語源学習 × 間隔反復の相乗効果

| アプローチ | 理解度 | 定着率 | 学習負荷 |
|-----------|-------|-------|---------|
| 丸暗記のみ | 低 | 低（すぐ忘れる） | 高（何度も繰り返す必要あり） |
| 丸暗記 ＋ 間隔反復 | 低 | 中（忘れにくいが思い出しにくい） | 中 |
| 語源学習のみ | 高 | 中（理解はしているが復習がないと薄れる） | 低 |
| **語源学習 ＋ 間隔反復** | **高** | **高** | **最小** |

Rootify は右下の「語源学習 ＋ 間隔反復」を実装する。これが「最小の努力で最大の結果」の科学的根拠である。

## 10. 課金トリガー設計（なぜユーザーはお金を払うのか）

### 10.1 課金判断の心理

田中 翔太が課金するのは「機能に払う」のではない。**「英単語が覚えられる自分」に投資する**のである。

| 心理 | 具体的なモーメント |
|------|------------------|
| 「このやり方なら覚えられる」 | 語源ツリーで ex- を学んだ直後、5つの単語が一気にわかった瞬間 |
| 「今までと違う」 | 1週間後の復習クイズで、語源から正解を導けた瞬間（忘れてなかった！） |
| 「もっとやりたい」 | 無料の語源数上限に達し、次の語源ツリーがロックされた時 |
| 「広告が邪魔」 | クイズとクイズの間に挟まるインタースティシャル広告にストレスを感じた時 |

### 10.2 広告設計（Freeユーザーの課金転換エンジン）

広告は「ウザいから課金する」ではなく、**「集中を邪魔される → 学習の流れが断たれる → 広告なしの体験がいかに快適か実感する」** という設計にする。

**広告を出す場所：**

| タイミング | 広告タイプ | 狙い |
|-----------|-----------|------|
| クイズ10問完了後 | インタースティシャル（全画面） | 「達成感の直後に中断される」ストレス。毎日繰り返されると課金動機に |
| 語源学習モードの切り替え時 | インタースティシャル | 「次の語源を見たいのに広告」→ 学習の流れが断たれるフラストレーション |
| ダッシュボード下部 | バナー（320×50） | 常時表示の軽いストレス |
| 語源ツリーマップ閲覧時 | バナー | 探索中の視覚ノイズ |

**絶対に広告を出さない場所：**

| タイミング | 理由 |
|-----------|------|
| クイズの問題間 | 学習中の集中を完全に破壊する。UX崩壊 |
| 語源分解ヒント表示中 | 「理解の瞬間」に広告を挟むと、アハ体験が消える |
| 学習ストリーク達成時 | 達成感の瞬間に広告を見せると、ポジティブな感情が損なわれる |

## 付録: 用語定義

| 用語 | 定義 | 備考 |

| 語源（Etymology） | 単語の起源・成り立ち。接頭辞＋語根＋接尾辞のパーツに分解できる | Rootify の学習の基本単位 |
