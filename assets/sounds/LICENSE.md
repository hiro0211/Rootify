# Sound Effects License

## Current Files (Synthetically Generated)

`correct.wav` and `incorrect.wav` are synthetically generated WAV files created
using Python3's `math` and `struct` standard libraries. They contain pure sine
wave tones and are not derived from any external work.

- **correct.wav**: 880 Hz chime tone with exponential decay (0.4s)
- **incorrect.wav**: 220 Hz low tone with fade envelope (0.3s)

These files are original works created for this project and are released under
**CC0 1.0 Universal (Public Domain Dedication)**.

## Upgrade Path

For production use, consider replacing with higher-quality CC0 sounds from:

- [Freesound.org](https://freesound.org) — search for "correct chime CC0" / "wrong buzzer CC0"
